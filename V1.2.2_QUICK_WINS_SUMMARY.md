## Practical Implementation Plan

### Priority 1: Real-Time Validation (Highest Impact)
**Current State**: Forms validate only on submit (line 1516-1520)
**Enhancement**: Add `touched` state and validate as user types

**Implementation**:
```jsx
// Add touched state (after line 635)
const [touched, setTouched] = useState({})

// Replace standard inputs with ValidatedInput
// Example for transmittingCountry (line 4555-4563)
<ValidatedInput
  value={formData.transmittingCountry}
  onChange={(e) => {
    handleInputChange('transmittingCountry', e.target.value.toUpperCase())
    setTouched({...touched, transmittingCountry: true})
  }}
  validate={(val) => {
    if (!val || val.length !== 2) return 'Must be 2-letter ISO code'
    if (!/^[A-Z]{2}$/.test(val)) return 'Must be uppercase letters'
    return true
  }}
  label={t(language, 'form.transmittingCountry')}
  required
  showValidation={touched.transmittingCountry}
  placeholder="e.g., NL"
  inputClassName={theme.input}
/>
```

**Files to Modify**: `App.jsx` (lines 4555-4576 for CRS, similar for FATCA/CBC)

### Priority 5: Keyboard Shortcut Help (Quick Win)
**Current State**: `KeyboardShortcuts.jsx` exists, shortcuts work, but no help overlay

**Enhancement**: Add `Ctrl+?` to show help overlay

**Implementation**:
```jsx
// Add state for help overlay (after line 640)
const [showKeyboardHelp, setShowKeyboardHelp] = useState(false)

// Add keyboard shortcut for help (in useKeyboardShortcuts)

  ...existing shortcuts,
  'ctrl+/': () => setShowKeyboardHelp(true)
})

// Add help overlay component (before closing main tag)
{showKeyboardHelp && (
  <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50">
    <div className={`${theme.card} rounded-2xl shadow-2xl max-w-2xl w-full mx-4 max-h-[80vh] overflow-y-auto`}>
      <div className={`p-6 ${theme.accent} text-white`}>
        <div className="flex items-center justify-between">
          <h3 className="text-xl font-bold">Keyboard Shortcuts</h3>
          <button onClick={() => setShowKeyboardHelp(false)}>
            <X className="w-6 h-6" />
          </button>
        </div>
      </div>
      <div className="p-6 space-y-4">
        {Object.entries(SHORTCUTS).map(([key, shortcut]) => (
          <div key={key} className="flex items-center justify-between">
            <span className={theme.text}>{shortcut.description}</span>
            <kbd className={`px-2 py-1 rounded ${theme.badge} font-mono text-xs`}>
              {shortcut.ctrl && 'Ctrl + '}{shortcut.key.toUpperCase()}
            </kbd>
          </div>
        ))}
      </div>
    </div>
  </div>
)}
```
